### [AutoValue AI](repo-link)

I built an end-to-end Machine Learning application to estimate the resale value of cars! 

Highlights: Data: Leveraged the Quikr Car Dataset, performing extensive data cleaning on messy string inputs. 

Algorithms: Evaluated Linear Regression, Lasso, and Random Forest. Lasso achieved an R² of ~0.58, with Random Forest providing the lowest Mean Absolute Error.
